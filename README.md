# Learnify – Online Learning Platform

A user-friendly online learning platform built with HTML, CSS, and JavaScript.

## About the Project

Learnify is a front-end web development project designed to help users explore online courses through a simple and clean interface.

## Features

- User registration and login interface
- Browse courses across multiple subjects
- Course enrollment interface
- My Courses section
- About page
- Contact page
- Interactive website navigation

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser localStorage for client-side storage

## What I Learned

- Front-end web development
- Website layout and styling
- JavaScript interactions
- Form handling and client-side data storage
- Organizing multiple web pages

## Future Improvements

- Backend integration
- MySQL database
- Secure authentication
- Improved course and enrollment management
